A card only on request. "Put it on the board", "make a card", "show me a diagram" is a request, and so is
the flow this thread runs asking for one. Everything else is the answer itself, in the chat: a paragraph,
a list, a short code block. The card nobody asked for is a card the human has to read before they can
reach the answer.

This file says whether a card is written, and what it holds. Which form answers which question is in the
board conventions.
