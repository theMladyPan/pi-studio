## [0.11.0] - 2026-11-26

- fix: Draw container logs as plain text — ANSI colour and cursor sequences, carriage returns and backspaces from programs that write a terminal stream (a Python REPL, a progress bar) are stripped and collapsed on the server, so the logs tab reads as lines instead of literal `[1;35m` garbage; the terminal drawer still takes the raw stream through `tail in terminal`.
- fix: Read the Git Graph's identity quietly — the repository info now lists the local and global config once each and picks `user.name` and `user.email` out of the lists, so a repository with no local identity answers `null` for it instead of logging an error row on every refresh.
- feat: Run a disposable shell from an image's right-click menu — `run shell ↗` opens a `--rm -it` container from the image's tag (or its id when dangling) in the terminal drawer, so the shell lives in the board's own pty and exits with the container removed.
- fix: Say a command had no output in the logs drawer instead of repeating the command — a quiet command such as an empty stash list now opens on a dim `[no output]` line under its meta grid, and a plain log line without a command behind it still opens on its full message.
- fix: Measure container CPU percent between the drawer's own polls by wall time instead of trusting the engine's previous sample — Podman's one-shot stats carry a zero previous sample, so the old formula read as a lifetime average that a burst of load barely moved, and its system counter counts busy time only, so the Docker formula overread it; the drawer now keeps each container's last CPU counter and divides the change by the seconds elapsed, so 8 busy cores read 800% on any runtime.
- feat: Draw a source card whose file is a page as the page itself — an `.html` or `.htm` file opens on the board in the editor's own sandboxed frame (scripts allowed, no origin of its own), so the card you asked for shows ready instead of its source; the frame is kept on the card while the file stands, so a repaint elsewhere does not reload it, an open in the editor still brings the code view back, and a file opened again into the card it already holds is news even when only its words or its hit line moved, so the card is drawn from the new words instead of keeping the old copy standing (the code view before it had the same gap).
- feat: Add a duplicate press to every card head — a thread comes back as a new instance with a new thread id, its turns and its session copied under a fresh session id so the conversation continues where the original left it, while the cards the original owns stay bound to it; a note, source or settled question comes back as a clone under a new id with no key and no saved place, answered by the same thread, and an open question or a thread with a run in progress is refused rather than copied mid-flight.
- fix: Name every left drawer in the board header — the activity and source control drawers lose their own rail heads with their close buttons (Esc and the header doors still close them), the header's open-panel label now names files and source control as it already named activity and search, and the source control total its rail head carried is gone, its per-group counts already standing below.
- feat: Show a thread's short id in its card head and let a click on it copy the whole id — the first eight characters of the thread's id sit in the head's right-hand row in mono, hovering shows the full id, and a click copies the full id to the clipboard (the footer repeats it if the clipboard refuses), so the separate copy glyph is gone.
- feat: Add a task queue to the kontainer drawer — each Docker or Podman action pops in blue while it runs, turns green or red when it finishes with its duration, and leaves five seconds after that (pausing while hovered, until the cursor leaves), so parallel actions stack instead of replacing one another; clicking a card opens its record in the detail sheet (what was asked, then what the engine said), which extracts the activity detail into the shared drawer furniture as one sheet with two instances; a failed task already carries its error, so the plain toast does not copy it.
- feat: Bring the consumption figure back to the message field — input/output tokens, requests and cost sit in the field's own row, right of the chips and left of send/stop, the per-thread figure the merged activity drawer no longer carries.
- feat: Add `report_status` and `get_board_status` so threads on a board cooperate on a fuzzy semaphore — a thread reports reading, writing, merging or system before the phase changes and pulls the board's phases before any merge, rebase or other operation that touches every worktree; a thread's first message also carries the others' phases as orientation, running children read by their role, and an unexpected finish leaves its error as a note where the board status can be read.
- feat: Add a `board_wait` tool so one thread can wait for another to finish and then carry on — for chaining, like merging work after the thread that made it is done; it takes a thread id or its first 8 characters and a timeout (default 600s), holds until the thread settles or the timeout lapses, and a timeout is a normal answer the caller decides on rather than an error, while idle and unanswered reads as failed, never done.
- fix: Keep a long error readable in the kontainer drawer's toast — the bubble has rounded corners and wraps its text, so a message that names the container it would not remove stays inside the bubble instead of running off its edge.
- feat: Add a plainly labelled Sources stratum to the kontainer drawer — Sources, Images, Containers and Wiring carry no numbering badges; recognized workspace compose files, Dockerfiles and Containerfiles appear as definition cards (even when no container runtime socket is up) with service pills, quick actions and dashed wires into the images they build, a source inspector previews the file alongside its linked images, containers and build details, right-clicking a source offers its stack or build actions without moving the selection, and opening a source closes the drawer and opens the file in the board editor.
- feat: Add a right-click menu to every kontainer drawer node — images, containers, ports, networks and volumes each offer the actions and the copies their inspector already carries, an item the node's own state rules out is greyed with its reason in the tooltip, a right press leaves the selection and the details panel as they stand — only `inspect` and `layers` open the panel — and `Esc` puts the keyboard back on the card the menu was opened on; the menu's `kill` arms the inspector's own button rather than leaving it reading `kill`, a keyboard press opens the menu on its card instead of the window's corner, a port's `open in browser` reaches an any-interface or IPv6 bind through a host a browser can dial, and a mount reads as `volume` or `bind` on its card and in its inspector rather than as the `vol` column it is drawn in, and the menu hangs on the page body instead of inside the drawer, so a press during the slide places it against the window rather than against the drawer's own box and rolling the drawer up puts the menu away with it; the volume prune sheet names what Docker will remove instead of a count the topology never carried, since it holds only mounted volumes.
- feat: Add a logs drawer on the right edge, opened with `l` or its toolbox door — the daemon's own stdout and stderr, every git command with its folder and exit, the Docker calls, a child's stderr, a plugin that would not start and the provider error behind a stopped run now land in one 5000-line ring that the drawer reads live, so what just happened is answered without opening the terminal the daemon was started from; every line is redacted as it is written, a secret never reaches the buffer, each row is cut to 120 characters until it is clicked open, the verbosity filter and the paused tail are the human's, and pi children can write a line of their own through `POST /log`; the kontainer drawer's own Engine calls and the engine's live events join the same ring — a container start or stop through the API is `info`, a death or an unhealthy health check is `error`, and the events stream's own failure is `error` too — so a container that stopped on its own is answered from the logs drawer as well, and an Engine line reads as the command a developer would have typed (`cd /home/.../chatbot podman restart chatbot_chatbot_1`) — the daemon's HTTP call translated, so it can be copy-pasted into a terminal — with the workspace it was asked from in its folder meta, so a 64-hex id is a parenthetical instead of the headline; and a command's expanded view now carries what the command answered — git's stdout, a CLI runner's output, or the engine's reply, head and tail when it is too long to hold — instead of the command again, so `git rev-parse --show-toplevel` opens on the path it printed.
- fix: Move the workspace and day from the title line into the foot of every PDF page and take the card id off the page — the title is followed by its rule alone, the foot carries title, workspace and day on the left and the page count on the right, and a markdown link now reads as its label alone, underlined and clickable, instead of the label followed by its address in parentheses.
- fix: Draw Polish and Czech letters with their own glyphs in the PDF instead of folding them to their base letter — letters the standard fonts have no byte for (ą, ł, č, ř …) come from an embedded subset face (DejaVu Sans, U+0100-U+024F) carried inside the file, with a ToUnicode map so the words stay copyable and searchable.
- fix: Take the card's name off the top of the PDF page — it was set as a heading over the words, and a reader downloading a note gets a second copy of it, while the foot of every page already names it there.
- docs: Prune `TODO.md` against the current tree — the workspace-forget entry is gone (the crossroads remove press shipped in 0.8.0, folder and board staying on disk), the raw-stream debug entry is gone (the logs drawer and the transcript drawer now answer it), the thread-fork entry is gone (the composer fork is treated as complete), the HTML entry shrinks to card bodies (the files editor already draws an opened page in a sandboxed frame), the Git Graph entry shrinks to the archive, the config export and the idle-thread checkout question (remote writes answer now, and a push inherits the shell's ssh key, agent and credential helper), and the type-checker and client-split figures are refreshed (34 of 92 daemon files exempt, the client at 15 434 lines).
- fix: Stop work branches from forcing the whole test suite with the no-cache flag — the gate now reads the diff by risk and prints its scope on every run, so docs and pure style never pay a full run, core logic still reruns what it touches, the middle ground is for the thread to call, and a full `--full` run belongs to merging into `main`; the content-hash cache stays the kernel, so no test is ever skipped by a label.

## [0.10.0] - 2026-11-26

- feat: Add a built-in kontainer top drawer (`k`) for Docker and Podman with live image-to-container-to-wiring topology, workspace filtering, event-driven Eco/Balanced/Live refresh modes, and compose/build/registry/prune tools; a container running an older build keeps an amber dashed conduit to the image its tag now names instead of losing its edge, sizes read in KB/MB/GB rather than the unit above them, an unpublished port says so instead of showing a `null` host port, telemetry is there as the drawer lands instead of three seconds later, the bar's alert count and the issues filter share one definition, a runtime badge keeps the case a socket path has on disk, and the log, inspect and layers tabs keep the detail they fetched instead of resetting to `loading…` whenever the topology or the stats refresh, so a selected container's output stays readable and live telemetry repaints the two metric cards in place, the inspector is dragged wide from its left edge at a width a reload keeps, and the drawer's name stands in the board header beside the workspace instead of in a bar of its own; a rejected action now shows its error rather than a success toast, a tab hands the terminal only the command the daemon built, the bar says why no runtime was found and offers a retry, a runtime is named by its label, a compose stack whose working directory lies outside the board's folder is refused before it is recreated and every compose action reaches the project it names, and the events stream ends with an `error` event when the engine fails mid-stream instead of stalling silently.
- feat: Cache test results by content hash — a whole-suite entry skips `npm run check` entirely when nothing changed, and per-file entries rerun only the test files whose imports changed, so an LLM loop no longer pays the full ~27 s suite for every edit; `PI_STUDIO_NO_CACHE=1` forces a full run.
- feat: Download both files when a note's download press is hit — one press now saves the note's own markdown as `.md` beside the pdf the daemon lays out, under the same name save one extension, so the editable source and the page leave together instead of the page alone.
- feat: Add a `delete` key that triggers deleting the thread card you are reading — it opens the same sheet the card's trash button opens, listing the card, conversation, folder and branch that would go, so the key alone never removes anything; a card with no trash, such as a note or an open question, answers to no delete key either.

- feat: Search file names in every folder from the files drawer — the filter walks the whole workspace in chunks instead of only the folders already open, so typing `README` finds every `README.md` on disk; a hidden toggle decides whether dotfiles join the walk, under the same excludes the tree shows, a click reveals the match in the tree, and the right-click menu works on a result as it does on a row.
- feat: Add a search drawer to the left column, opened by `ctrl+f` or its header door — a full-text search over file contents grouped by file with the match picked out in each snippet, match-case, whole-word and regular-expression modes, and a batch replace whose toggle switch picks between every file shown and only the ticked ones; a replace asks first, names whether a git checkout can undo it, checks each file against the stamp the search read, and a click on a hit opens the file at its line in the editor; while it is open the header names it "Search and replace", as the git graph names itself, and its own head carries the workspace path, as the files head does.
- fix: Keep the models pi has listed in memory for six hours even when a read omits them, and treat a table that comes back more than a fifth smaller than the one known as a short read rather than a smaller machine — the known list stays, the picker says why, and pi is asked again after thirty seconds, so a slow answer from OpenRouter no longer refuses spawns for models that are still there.
- feat: Merge the activity and cards left drawers into one `activity` drawer holding open and closed cards with inline collapsible settled logs per thread card and a right-click menu for `reopen` and `debug` (transcript); drops the `c` shortcut, the click-to-center shortcut, the drawer count badges, and the running-activity drawer strip, and starts closed by default.
